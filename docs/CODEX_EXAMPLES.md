# Codex에 전달할 작업 요청 예시

이 폴더를 Codex 프로젝트 작업 루트로 열고 자연어로 요청합니다. 명령어에 `LÖVE2D` 연동을 추가할 필요 없습니다.

## 예시 1: 기존 VFX 팔레트 변경

> pixel-vfx 스킬을 사용해 `tools/pixelfx`에서 `fire/torch`를 검색해 줘. 원본 코드는 수정하지 않고 동일 구조의 푸른 불꽃 변형을 제작할 수 있는 명령이나 레시피를 `recipes/vfx/`에 만들어. 3가지 팔레트를 비교 렌더링하고 `outputs/vfx/`에 PNG 시트·JSON·미리보기를 저장해. `tools/check.mjs`도 실행해.

## 예시 2: 새 이펙트 제작

> pixel-vfx 스킬을 사용해 2D 도트형 전기 충격파 이펙트를 만들어 줘. pixelfx의 가장 가까운 레시피 2~3개를 먼저 확인하고, 3개의 서로 다른 모션 시안을 만들고, 컨택트 시트와 루프를 검수한 뒤 하나를 확정해. 프레임별 투명도와 파티클 움직임이 자연스러운지 점검하고 `outputs/vfx/`에 저장해.

## 예시 3: Kenney 원본 색상 변형

> pixel-sprite 스킬을 사용해 `references/kenney/`에서 직접 선택한 원본 아이템 이미지를 찾아. 원본 픽셀의 정확한 위치와 투명도는 보존하고 색상 팔레트만 4종 바꿔 `outputs/sprites/`로 출력해. Kenney 팩의 출처와 원본 경로를 기록해. 신규 이미지 생성 API는 호출하지 마.

## 예시 4: 애니메이션 검수

> asset-review 스킬로 `outputs/animations/`의 JSON과 PNG 시트를 검사해. 각 프레임 좌표가 이미지 범위 안에 있는지, 프레임 크기와 fps, 투명 배경이 올바른지 확인하고 문제가 있는 프레임만 보고해. 임의로 원본을 덮어쓰지 마.

## 예시 5: 현재 사용 가능한 도구 진단

> 현재 프로젝트를 읽고 `tools/`에 설치된 오픈소스와 버전·라이선스, Python·Node 환경을 검토해. 수행 가능한 작업과 실제 설치가 필요한 작업을 구분해서 알려줘. 사용자 승인 없이 유료 API를 호출하거나 외부 서버에 업로드하지 마.
